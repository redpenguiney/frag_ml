1. git clone the repository
2. Install all the neccesary packages.
  - Be advised that gen_data_protein.py requires Uni-Dock (https://github.com/dptech-corp/Uni-Dock). Uni-Dock uses CUDA and thus gen_data_protein.py will not work on all platforms. 
3. Run train_model.py first in order to train the machine learning algorithm. Make sure to input the correct paths of the CSV.
4. Run frag_predict.py in order to predict the best fragment for the inputted drug. Make sure to put the correct paths of the CSV.
5. combine_frag.py combines 2 fragments into one drug. 
6. gen_data.py generates a dataset of drug SMILES and its frag SMILES. Enter a csv of drug SMILES, protein, and coordinates.
   Example input through terminal : python gen_data.py --input_csv "input.csv" --mol2_path "mTOR.mol2" --docking_dir "dockdir" --target_name "mTOR" --center_coords 68.0658 -5.1678 -54.97 --box_sizes 98.194 95.5592 116.24 --output_path "output.csv"

   However, it has been succeeded by two other different scripts for generating data. 
   gen_data_protein.py is operated in the same way as gen_data.py, creating a dataset of drug-fragment SMILES pairs given drug SMILES and a protein to dock with, with the exception that it requires a .pdbqt for its protein input rather than a .mol2 file. The best fragment is determined based on docking scores and the Rule of 3 out of candidates generated by applying Fraggle-Sim, BRICS, and Recap to each drug molecule.

   Be wary when specifying box sizes with gen_data_protein.py; they should given in angstroms and not any other unit.
